⚡ Deterministic Finality

No live fork choice: a block is final once ⌊2N/3⌋+1 validators precommit it, and it can never be reversed. Two-phase voting (prevote, then precommit) on (height, round, transition_id); every signature commits to this chain. Design →

🔄 Adaptive Committee

Committee size, minimum bond, and eligibility thresholds adjust deterministically based on qualified operator depth.

📦 UTXO Ledger

UTXO model with P2PKH addresses and Ed25519 signatures. Two transaction formats, both valid from genesis: Tx (transparent) and TxV2 (confidential-capable).

📡 Your Wallet Verifies

The wallet does not take a server's word for its balance. It starts from the genesis built into it, follows each validator committee, and checks every coin against the validators' signatures. It asks several servers: none can invent a coin, and one honest server is enough to reveal a hidden one. How it works →

🔐 Address Format

Ed25519 keys → HASH160(pubkey) → Bech32-like encoding (not standard SegWit Bech32) with a 4-byte SHA256d checksum. HRP: sc (mainnet) / tsc (testnet).

⚖️ A Fair Launch, by Published Rules

Who holds the coins decides whether a chain can be trusted, so these rules are fixed in the code and the published launch plan, where anyone can check them:

  • No premine and no sale. Genesis creates zero coins. Every FLS, including mine, is earned as a validation reward under the public emission schedule.
  • Genesis validator slots are drawn, not chosen. Submitted keys are ranked by a Bitcoin block hash mined after submissions close, which nobody, including me, can know in advance. Ceremony →
  • I cannot control consensus. At most ⌊(N−1)/3⌋ of the N genesis slots can be mine, so the other validators always form a quorum without me.
  • No treasury wallet. The 10% reserve is protocol state, released by fixed rules after the supply cap; no person holds its keys. Economics →
  • Everything is reproducible. Code, genesis files and release builds are public under the MIT license; anyone can rebuild them and check the published hashes.

🕶️ Confidential UTXOs (enabled from genesis)

Confidential outputs hide their amount (Pedersen commitment + range proof, no trusted setup) and pay a one-time key instead of an address. The wallet supports shield (transparent → confidential), confidential → confidential, and unshield (confidential → transparent).

Amounts are private only in confidential → confidential transfers; shield and unshield amounts can be computed from their public parts. The transaction graph, fees and the total confidential supply are always public. There is no sender anonymity.

🚀 Quick Start: Testnet Node (Linux)

Mainnet has not launched. Until it does, run a node on the public testnet. One command installs the dependencies, builds, and starts the node as a background service:

git clone https://github.com/FinalisCore/finalis-core.git
cd finalis-core
FINALIS_NETWORK=testnet SERVICE_NAME=finalis-testnet ./scripts/start.sh

# Watch it sync
sudo journalctl -u finalis-testnet -f

Default ports: testnet P2P 19540 · Lightserver 19544  |  mainnet (after launch) P2P 19440 · Lightserver 19444

Becoming a testnet validator, opening ports, troubleshooting: the joining guide. Never reuse a testnet validator key on mainnet.
